# Искрица: Пътят на светлината

Оригинален 2D side-scrolling платформър на Python и pygame-ce – университетски проект.

Сенкоглав е откраднал светлината от три свята. Искрица – малък дух-пламъче – тръгва
да я върне през **Шепнещата гора**, **Кристалната пещера** и **Сенчестата крепост**.
По пътя събира искри и слънчеви кристали, прескача пропасти и лава и накрая се
изправя срещу Сенкоглав в Тронната зала.

* 6 нива в 3 свята, всяко със собствена палитра и паралакс фон; бос с 3 фази накрая
* прецизна физика: ускорение и триене, скок с изчислена сила, променлива височина,
  coyote time, jump buffering, по-силна гравитация при падане
* нивата са **текстови файлове** – ново ниво се добавя без промяна в кода
* валидатор, който с графово търсене доказва, че изходът е достижим
* всичката графика и всичките звуци се генерират програмно (нула външни файлове)
* записан прогрес (отключени нива, рекорди, кристали) в `data/save.json`
* около 400 автоматични теста, включително headless тестове на цялата игра

## Инсталация

Нужен е Python 3.11 или по-нов.

**Windows**
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**macOS / Linux**
```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Зависимостите са само две: `pygame-ce` (графика, звук, вход) и `pytest` (тестове).

## Стартиране

```
python main.py                 # главно меню
python main.py --level 2-1     # директно в ниво 2-1 (или --level 3 за третото ниво)
python main.py --debug         # с включен debug режим
```

## Контроли

| Клавиш | Действие |
|---|---|
| ← → / A D | движение |
| Space / W / ↑ | скок (задръж за по-висок скок) |
| Shift | бягане |
| X / J | изстрел (с power-up „Пламък“) |
| ↓ + скок | пропадане през дъска `=` |
| Esc / P | пауза |
| F1 | debug режим: хитбоксове, скорост, FPS, състояние на героя, dead zone на камерата |
| Enter | избор в менютата |

Клавишите се сменят в `config.py` (`KEY_BINDINGS`).

## Правила

* 3 живота; +1 живот на всеки 100 искри (монети) и от блок „Фенерче“.
* **Малка** форма: един удар = загубен живот. **Голяма** форма (Жарава): един удар
  я връща в малка и може да чупи блоковете `B`. **Пламък**: голяма форма, която
  изстрелва отскачащи искрови заряди. **Комета**: 8 s неуязвимост, враговете
  падат при допир.
* Скок отгоре побеждава врага; страничен допир наранява.
* Чекпойнтите (фенери) запомнят мястото за възраждане.
* Точки: искра 10, кристал 500, Мъхчо 100, Скокльо 150, Нощниче 200,
  Бодлоцвет 200, Сенкоглав 5000, всяка оставаща секунда 10.

## Тестове

```
python -m pytest              # всички тестове (~2 минути заради 60-секундните стрес тестове)
python -m pytest -v           # подробно
python -m pytest --deselect tests/test_stress.py   # бързите (~20 s)
```

Тестовете работят без прозорец и без звук (`SDL_VIDEODRIVER=dummy`, задава се
автоматично в `tests/conftest.py`) и не пипат истинския `data/save.json`.

## Как да създам ново ниво

1. Създай `levels/4-1.txt` (името определя реда на нивата).
2. Напиши секция `[meta]` и нарисувай картата в `[map]` – пълната легенда е в
   [LEVEL_FORMAT.md](LEVEL_FORMAT.md).
3. Провери го: `python -m level.validator levels/4-1.txt`
4. Изиграй го: `python main.py --level 4-1`

## Документация

| Файл | Съдържание |
|---|---|

## Структура

```
main.py            входна точка
config.py          всички константи
engine/            основен цикъл, екрани, вход, камера, рисуване, звук, свят
physics/           тела, колизии, заявки към картата
level/             тайлове, парсер, валидатор, reachability, прогрес
entities/          герой, врагове, бос, снаряди, предмети, платформи, опасности
ui/                HUD, менюта, преходи
levels/            6-те нива (.txt)
tests/             pytest тестове
```

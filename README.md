# Искрица: Пътят на светлината

Оригинален 2D side-scrolling платформър на Python и pygame-ce.

## Инсталация (Windows)
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
(macOS/Linux: `source .venv/bin/activate`)

## Стартиране
```
python main.py
```

## Тестове
```
python -m pytest -v
```

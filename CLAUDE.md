# CLAUDE.md – конвенции на проекта „Искрица: Пътят на светлината“

Университетски проект: 2D платформър на Python + pygame-ce. Нивата са текстови файлове.

## Команди
- Виртуална среда: `python -m venv .venv` и `.venv\Scripts\activate` (Windows)
- Инсталация: `pip install -r requirements.txt`
- Стартиране: `python main.py` (опции: `--level 2-1`, `--debug`)
- Тестове: `python -m pytest -v` (бързи: `--deselect tests/test_stress.py`)
- Проверка на ниво: `python -m level.validator levels/1-1.txt`

## Конвенции (проверяват се автоматично от `tests/test_style.py`)
- PEP 8, максимум 100 символа на ред.
- Type hints навсякъде и `from __future__ import annotations` във всеки модул.
- Docstrings (Google стил) за всеки клас и публична функция. **Език: български.**
  Имената в кода (класове, функции, променливи) са на английски.
- Без магически числа – всички константи са в `config.py`. Изключение: координатите
  в рисуващите функции на `engine/assets.py` (това са „пиксели на рисунката“, а не
  правила на играта).
- Функции до ~40 реда (тестът допуска 45). Яснота пред „хитър“ код – читателят е студент.
- Физиката, колизиите, парсерът, валидаторът и логиката на entities НЕ зависят от
  дисплей (pygame.Rect е позволен, но без `pygame.display`/`pygame.draw`).
- Светът (`engine/world.py`) не рисува и не пуска звук – записва събития (`GameEvent`),
  които `Playing` превръща в частици и звуци.
- Коментари само при нетривиалните формули – обясняват „защо“, не „какво“.
- Всички движения се умножават по `dt`. Логиката върви на фиксирана стъпка `FIXED_DT`.
- Без външни графични/звукови файлове: всичко се генерира програмно
  (`engine/assets.py`, `engine/audio.py`).
- Оригинално съдържание: никакви персонажи, имена или ресурси от чужди игри.

## Работен цикъл за всяка промяна
План → имплементация → pytest → headless smoke test (`SDL_VIDEODRIVER=dummy`) →
commit `stage N: описание` → обновяване на PROGRESS.md.
Никога не променяй тест само за да мине – поправи кода.
Тестовете никога не пишат в истинския `data/save.json` (виж `tests/conftest.py`).
